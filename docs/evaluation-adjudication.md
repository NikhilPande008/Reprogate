# Evaluation Adjudication Rules v1

1. Freeze corpus version, rubric version, and this document before evaluated
   investigations begin. Do not replace cases after observing system outcomes.
2. Retain every reviewer assessment and supersession audit record. A consensus
   view is derived metadata, never a replacement for individual judgments.
3. When reviewers disagree on claim fidelity, test fidelity, evidence validity,
   or usefulness, mark the case **unresolved** unless a third qualified
   adjudicator writes a packet-hash-bound rationale.
4. An adjudicated result must retain both original labels, the adjudicator role,
   timestamp, rationale, and whether the classification was visible.
5. Report unresolved cases in denominators and stratified results. Never
   silently recode them as aligned, negative, or operational failures.
6. Operational failures (setup, timeout, unsupported runner, malformed/missing
   artifacts) remain a distinct outcome class and are excluded only according
   to the frozen metric definition.
