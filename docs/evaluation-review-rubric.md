# Independent Review Rubric v1

Review the immutable evidence packet, not a regenerated run. Where practical,
hide the system classification during initial review. Each item is `ALIGNED`,
`MISALIGNED`, or `UNCLEAR`; `UNCLEAR` and `MISALIGNED` require a rationale.

1. **Claim fidelity** — the bounded claim accurately represents the report,
   including stated constraints and material missing information.
2. **Test fidelity** — the changed focused test encodes that bounded claim,
   rather than a weakened, fabricated, nearby, or unrelated behavior.
3. **Evidence validity** — the changed executable test, exact selection,
   structured result, clean execution, and rerun evidence support the result.
4. **Non-confirming appropriateness** — for outcomes other than confirmation,
   the conservative classification reflects available evidence and does not
   assert semantic truth.
5. **Maintainer usefulness** — score 1–5 whether the packet would help a
   maintainer make a decision faster or with greater confidence; explain any
   score below 4.
6. **Public-action appropriateness** — record whether a human-approved draft
   would be appropriate. This never authorizes posting.

Record reviewer cohort, packet hash/version, confidence, reason tags, and the
review date. Two independent reviewers are required for every included case.
